CARA PAKAI ULILMART POS
=======================
1. MULAI-KASIR.bat    Jalankan kasir. Pertama kali butuh internet (1-3 menit),
                       sekaligus membuat ikon "Ulilmart POS" di Desktop.
2. BERHENTI-KASIR.bat  Matikan server (menutup jendela kasir saja tidak mematikannya).
3. update.bat          Ambil versi terbaru. Data toko dicadangkan dulu.
4. HAPUS-APLIKASI.bat  Hapus aplikasi (menawarkan cadangan data ke Desktop dulu).

Auto-start saat Windows menyala: MULAI-KASIR.bat --startup  (matikan: --remove-startup)

Perlu: Windows + Node.js LTS (nodejs.org). Jika bermasalah, lihat file server.log.
